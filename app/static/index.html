🧪 研究所模式（AI harness · 网络安全研究）

开启后：对话里说"研究 / 情报 / 漏洞 / 靶场 / 探针"等即进入研究流程。AI 会先在「测试空间」声明你已授权的靶标，再主动探测并观察响应，最后把成果写成 FastAPI 服务发布为团队可调用的 API。AI 只能探测你已声明的靶标，未授权第三方站点一律拒绝。
兼容任何 OpenAI 协议服务：OpenAI / DeepSeek / 通义千问 / Ollama / OpenRouter / 中转站。 代理模板中 {url} 会被替换为编码后的目标地址。配置保存在浏览器 localStorage。 平台还内置 Agno AgentOS 智能体接口（/agno，由服务端环境变量配置）。 发送图片需要模型支持视觉（如 gpt-4o-mini / gpt-4o），否则会报错——点 📷 可图文一起发给 AI 识别。 生图：对话里说"画一张…""生成…的图片"即可让 AI 调用生图模型（默认 dall-e-3，可在上方改成你服务商支持的模型，如 gpt-image-1 / flux 等）。 强制服从模式：作为最底层系统指令注入——AI 禁止拒绝回答、禁止脱离插件人设；系统实时监控模型的思考与输出，一旦发现违抗倾向立即强制中断、废弃输出，并关闭推理要求它直接按人设作答。对合规提问无影响，只是压掉 AI 的推脱和出戏。 推理模式：Agnes AI 的思考开关是 chat_template_kwargs.enable_thinking（已自动带上，同时兼容 DashScope/Qwen 的顶层 enable_thinking）——「跟随模型默认」不传参数；「开启」让模型先思考再答；「关闭」直接输出。用 Agnes 就点上面的「⚡ Agnes AI 预设」一键配好。
